FAQ

Do I need an account or API key? / 需要账号或 API key 吗？
No. Everything works on-device with Apple's local engines out of the box. Cloud engines are an optional advanced feature where you bring your own API key.
不需要。开箱即用，全部功能由 Apple 端上引擎本地完成。云端引擎是可选进阶功能，需自备 API key。

Where is my data stored? / 数据存在哪里？
On your device, and (if signed in) in your personal private iCloud. The developer has no access. See the Privacy Policy.
在你的设备本地，以及（若登录）你个人的私有 iCloud。开发者无法访问。详见隐私政策。

How do I record system audio? / 怎么录系统音频？
On Mac, grant the "System Audio Recording" permission when prompted; the app captures app playback alongside your microphone. On iPhone, start a recording, then enable the screen-broadcast capture when prompted.
Mac：按提示授予「系统音频录制」权限，即可与麦克风同时录制。iPhone：开始录音后按提示开启屏幕广播采集。

Which languages are supported? / 支持哪些语言？
Transcription and translation languages follow Apple's on-device engine support and download on demand in system settings. Optional cloud engines extend coverage.
转录/翻译语言跟随 Apple 端上引擎支持范围，按需在系统内下载；可选云端引擎可扩展覆盖。
